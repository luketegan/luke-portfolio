# Luke Tegan Portfolio

Personal portfolio built with React and Vite.

## Run it on your Mac

```
cd ~/Desktop/luke-portfolio
npm run dev
```

Open the local address it prints. Press Control + C in Terminal to stop it.

## Where to edit things

- `src/data/content.js`: project text, results, experience, and links
- `src/App.jsx`: page layout and homepage, About, and Contact wording
- `src/style.css`: colors, fonts, and spacing
- `public/resume.pdf`: the résumé behind the Résumé button
